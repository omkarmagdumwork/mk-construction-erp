# MK Construction & Builders: Website

React + Vite + Tailwind CSS v4 + Framer Motion.

## Run
```bash
npm install
npm run dev
```

## Customize
- Content (name, phone, stats, services, projects): `src/data.js`
- Colors and fonts: `src/index.css`
- Logo: replace `public/images/logo.png`
- Real photos: add `hero.jpg`, `project-1.jpg`, `project-2.jpg`, `project-3.jpg` to `public/images/`.
  They are used automatically; the `.svg` artwork is the fallback.
